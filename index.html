Understanding the Job Market

By Gian Carlos V. Tan, BSCS - IV | April 2025

Using a dataset of Job Listing data from glassdoor, we will look into certain factors that affect the salary range of a Job. We look into this type of analysis to create or set realistic salary expectations and help future job seekers seek out possible roles that might land them their ideal salary range. This also helps employers look into what other companies of the same sector pay their employee and therefore aid them in aligning their salary ranges with the market standard.

About the Dataset

The dataset is compilation of US job postings in Glassdoor from 2017. It is used to analyze and predict salaries.

Data Analysis Process

There are several steps to finding meaningful trends and insights based on the dataset:

  1. Loading the Dataset
  2. Cleaning and Processing the Dataset
  3. Analysis and Visualizations

Data Cleaning

When cleaning the dataset we look into first if there are fields missing or if there are dirty data.


        analysis_df.isnull().sum()

If there are undesired values, we will simply remove those values.


        analysis_df = analysis_df[analysis_df['Founded'] != -1]
        analysis_df = analysis_df[analysis_df['Size'] != '-1']
        analysis_df = analysis_df[analysis_df['Size'] != 'Unknown']
        analysis_df = analysis_df[~analysis_df['Salary Estimate'].str.contains('Per Hour', case=False)]

Next thing we want to do is group the salary ranges into categories such as low,medium and high range. To do this, we have to extract the currency value from the salary range. Therefore, we can get first the data and then split it into two columns, max and min. Then get the average based on that.

In the code below, we extract the salary ranges and create separate columns for it. 

        
          import re

          def extract_salary_range(salary_str):
              salary_str = re.sub(r'\(.*\)', '', salary_str)
              salary_str = salary_str.replace('Employer Provided Salary:', '').strip()
              
              salary_str = salary_str.replace('$', '').replace('K', '000')
              
              min_salary, max_salary = salary_str.split('-')
              
              min_salary = int(min_salary)
              max_salary = int(max_salary)
              
              return min_salary, max_salary

          analysis_df[['min_salary', 'max_salary']] = analysis_df['Salary Estimate'].apply(lambda x: pd.Series(extract_salary_range(x)))

          analysis_df.head()

Using the min and max ranges we can now find the average salary.

        
          def get_avg_salary(min_salary, max_salary):
              return (min_salary + max_salary) / 2

          analysis_df['avg_salary'] = analysis_df.apply(lambda row: get_avg_salary(row['min_salary'], row['max_salary']), axis=1)
          analysis_df.head()

We can now set a threshold for our salary ranges. In our case, we have set anything below 50k annual to entry level or low, between 50k and 100k annual to medium and above 100k as high. Note: That this is an estimate and a complete generalization, salary ranges might vary by state, location and other factors.

        
          def categorize_salary(avg_salary):
            if avg_salary < 50000:
                return 'Low'
            elif avg_salary <= 100000:
                return 'Medium'
            else:
                return 'High'
                  
          analysis_df['salary_level'] = analysis_df['avg_salary'].apply(categorize_salary)

We will then now categorize the year founded column into meaningful groups:

        
          def categorize_founded_year(year):
            if year < 1900:
                return 'Pre-1900'
            elif year < 1950:
                return '1900–1949'
            elif year < 2000:
                return '1950–1999'
            else:
                return '2000–Present'

        analysis_df['founded_group'] = analysis_df['Founded'].apply(categorize_founded_year)
